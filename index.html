Frequently Asked Questions (FAQ)

Does Azigizaro Enterprise work completely offline? +
Yes! All inventory, customer records, and transaction logs are stored locally in your browser. You can register sales without an active internet connection.
How does multi-device real-time sync work? +
By entering a unique Store Sync Key in your settings, terminals link via Firebase Realtime Database so sales and stock changes sync live across your devices.
What Mobile Money networks are supported? +
We accept MTN Mobile Money, Telecel Cash, and AT Money directly through integrated Paystack payments in Ghanaian Cedis (GH₵) with error handling checks.
How do I protect my stock data from unauthorized edits? +
The system features built-in hash-form security PIN verification (Default code: 1234 shown as ####). Adding new items or modifying stock requires entering this security code.
